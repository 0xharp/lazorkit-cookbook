# LazorKit Cookbook Documentation

Welcome to the LazorKit Cookbook documentation! This cookbook demonstrates practical LazorKit SDK integrations for Solana dApps.

> **Note**: We call these "Recipes" following the cookbook metaphor, while the URL paths use `/examples/` for clarity.
